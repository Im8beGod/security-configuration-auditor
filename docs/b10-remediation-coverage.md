# B10 reviewed remediation coverage

Reviewed preview coverage includes Cisco SSH v2, SSH-only VTY, idle timeout, remote logging, and NTP; FortiOS SSH/no-Telnet interface access and administrator timeout; Junos SSH/no-Telnet service and login timeout; and Arista EOS Telnet shutdown and remote logging. Every procedure is profile-scoped and includes prerequisites, warnings, verification, and rollback guidance. Unsupported logging, NTP, TLS, trusted-host, and access-class procedures remain unavailable rather than being synthesized.
