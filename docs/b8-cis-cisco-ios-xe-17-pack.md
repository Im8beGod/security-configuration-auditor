# B8 CIS Cisco IOS XE 17.x scoped technical pack

`cis_cisco_ios_xe_17_v2_2_1_scoped_technical` version `1` is a narrowly scoped
technical prototype for the CIS Cisco IOS XE 17.x Benchmark v2.2.1. It applies
only to `cisco.ios_xe.17@1.0.0`; it is not applicable to FortiOS, Junos, other
Cisco families, or unsupported IOS XE versions.

The authorized official PDF was accessed locally on 2026-09-09. Its filename is
`CIS_Cisco_IOS_XE_17.x_Benchmark_v2.2.1.pdf`, its release date is 2025-07-17,
and its SHA-256 is
`e5330afdf64cc7a44ba051733e7b3a5b835d7d341610dddb5d5292eabe126b25`.
The repository retains only compact provenance, identifiers, level/status
metadata, and locally authored objectives. It does not redistribute the PDF or
substantial CIS recommendation, audit, rationale, or remediation prose.

The pack contains eleven selected identifiers: 1.2.2, 1.2.5, 1.2.8, 2.1.1.2,
2.2.1, 2.2.4, 2.3.1.1, 2.3.1.2, 2.3.1.3, 2.3.1.4, and 2.3.2. Six use bounded
existing Cisco EffectiveStates for source restriction, VTY timeout, logging,
remote logging, NTP authentication, and NTP server presence. Five remain
manual where the available semantics cannot safely prove the complete
recommendation. Missing, conflicting, or multiple native scopes are UNKNOWN,
never PASS.

This is not full CIS Benchmark coverage, CIS-CAT, CIS certification, or CIS
SecureSuite certification. It does not assert key relationships, crypto suite
properties, defaults, policy, procedure, source authority, or operational
health.
